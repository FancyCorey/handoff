# Branding

## The current logo

<img src="brand/handoff-logo-512.png" width="96" alt="The current Handoff logo">

White over-ear headphones whose headband carries a small yellow arrow, on a blue-to-indigo gradient (`#1FA2C4` → `#3D3BB7`). The master is [`brand/handoff-logo.svg`](brand/handoff-logo.svg), drawn in the 108×108 Android adaptive-icon grid.

### How it holds up

| Where | Size | Result |
|---|---|---|
| README, store icon | 120–512 px | Clear. The arrow reads as "moving on". |
| Android launcher | 48 dp (≈ 108–192 px on screen) | Clear on light and dark wallpapers, because the icon carries its own gradient background. The monochrome layer works for Android 13+ themed icons. |
| Windows taskbar, installer | 32–48 px | Recognisable as headphones. The arrow is only a few pixels. |
| Quick Settings tile, notification icon, tray | 24 px | Reads as a generic headphone symbol. The arrow is about 3 px and effectively disappears. |

The mark says "audio" much more strongly than "moving between devices", and at small sizes it's indistinguishable from any headphone icon. That's the main reason to redesign it before a wider launch.

### Direction for a new mark

Prioritise **movement between devices** first and **audio** second:

- two endpoints joined by a single flowing path or hand-over motion, which may hint at a headband shape;
- simple, geometric, one or two strokes, legible at 24 px and in one colour (Android themed icons, the notification icon, the Windows tray);
- no detailed headphone drawing, no tiny arrows, no gamer or neon styling;
- not the Bluetooth rune as the identity, and nothing resembling Apple's Handoff, AirDrop or Continuity icons or Google's Quick Share / Nearby Share.

No new artwork is committed yet. The current logo stays until a replacement is designed and checked at every size below.

## Where the logo lives

Replacing the logo means updating all of these together:

| File | Used for | Notes |
|---|---|---|
| `docs/brand/handoff-logo.svg` | Master artwork | Glyph in the 108×108 adaptive-icon grid |
| `docs/brand/handoff-logo-512.png` | README header, Play Store icon (512×512) | Generated by `tools/IconGen.java` |
| `app/src/main/res/drawable/ic_launcher_background.xml` | Android adaptive icon, background layer | Gradient |
| `app/src/main/res/drawable/ic_launcher_foreground.xml` | Android adaptive icon, foreground layer | Keep inside the 66 dp safe zone |
| `app/src/main/res/drawable/ic_launcher_monochrome.xml` | Android 13+ themed icon | Single colour |
| `app/src/main/res/mipmap-anydpi/ic_launcher.xml` | Adaptive icon definition (also the round icon) | References the three layers |
| `app/src/main/res/drawable/ic_logo.xml` | In-app header logo (`Components.kt`, `Logo`) | |
| `app/src/main/res/drawable/ic_tile.xml` | Quick Settings tile and notification small icon | Must be a single-colour silhouette |
| `desktop/src/main/resources/handoff.ico` | Windows installer, shortcut and taskbar icon | Multi-size ICO, generated by `tools/IconGen.java` |
| `desktop/src/main/resources/handoff.png` | Windows app header logo | Generated |
| `desktop/src/main/resources/tray.png` | Windows tray icon | Generated; check at 16 and 24 px |
| `tools/IconGen.java` | Renders the PNG and ICO files from the shared geometry | Update its paths along with the vectors |
| Play Console | Store icon (512×512) and feature graphic (1024×500) | See [PLAY_STORE.md](PLAY_STORE.md#store-assets-checklist) |

After replacing, check the launcher icon on light and dark wallpapers, the themed icon, the tile and a notification on Android, and the installer, taskbar and tray on Windows.

## Licensing

The current logo is original artwork for this project and is released under the project's [MIT License](../LICENSE), as [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) says. That grant stays in place for the current logo and every copy already distributed.

If the project later wants official builds to be distinguishable from forks, a **new** logo could be published under separate brand terms (for example a short `TRADEMARKS.md` asking forks to use their own name and icon, while the code stays MIT). That is optional: this project puts access first, and there is no plan to restrict the current logo.

## Name

Apple uses "Handoff" as the name of one of its Continuity features. The overlap is a risk to review before a Google Play launch or any marketing. See [PLAY_STORE.md, Name risk](PLAY_STORE.md#name-risk). Handoff is not affiliated with Apple and doesn't work with Apple's Handoff.
