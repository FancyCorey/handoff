## What's changed

- **Prefer SBC on Android.** If Bluetooth audio cuts out, open your headphones in Handoff and choose **Bluetooth audio → Prefer SBC** on supported devices running Android 13 or newer. Android asks you to allow access to that pair. If audio is playing, Handoff waits for a pause and tells you when Android confirms SBC. The choice applies to this phone or tablet. Select **Automatic** to let Android choose again on the next connection.
- **Less Bluetooth activity during playback.** Background searches stop when music starts, and routine status updates skip the Bluetooth route while music plays. Moves can still find linked devices, and Handoff leaves the new audio connection in place after a successful move. When the old device is still connecting, Handoff waits for that connection attempt to end before confirming release.
- **More detail in shared reports.** The report shows the codec Android returned for each connected pair that Handoff can read. The Bluetooth log distinguishes Classic and LE events when Android identifies them, and shows when nearby advertising rotates or scanning starts and stops.

Update **both** devices if you use Handoff between them.

## Which file do I need?

| Your device | Download |
| --- | --- |
| Android phone or tablet (Android 12 or newer) | **Handoff-0.8.2.apk** |
| Windows 10 or 11 PC | **Handoff-0.8.2-setup.exe** (recommended) or **Handoff-0.8.2.msi** |
| Windows, without installing anything | **Handoff-0.8.2-windows-portable.zip**. Unzip it and run `Handoff.exe`. |

**Already using Handoff?** Use **Settings → Check for updates** in the Android GitHub edition or **Settings → Check** on Windows to keep your links and headphones. The Android Google Play edition updates through Google Play. An Android test build signed with a different key needs an update signed with that same key.

See the [getting started guide](https://github.com/FancyCorey/handoff/blob/v0.8.2/docs/GETTING_STARTED.md#if-something-goes-wrong) for playback troubleshooting. If AAC still cuts out, share a report with the time it happened and how playback recovered. [Open an issue](https://github.com/FancyCorey/handoff/issues).
