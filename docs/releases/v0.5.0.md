## Handoff 0.5.0

**Updates built in.** Handoff can now check this page for new versions (Settings → Check for updates, or once a day if you turn that on). Every update is signature-checked before it is installed.

**New**
- Cancel a move while it is running, on Android and Windows.
- Leave the move screen at any time; tap the headset (Android) to see the progress again.
- Your devices find each other straight after a restart, even on networks that block discovery.
- A phone or PC hotspot can serve as the shared network when there is no Wi-Fi.
- Full open-source notices in Settings → Open-source licenses.

**Fixed**
- Moving from Windows failed with "error 1168" when the headset's audio services were already off.
- Windows now fully lets go of single-point headsets (media, calls and remote control).
- Opening Handoff on Windows again shows the running window instead of starting a second copy.

**Downloads**
- **Android 12+:** `Handoff-0.5.0.apk`
- **Windows 10/11:** `Handoff-0.5.0-setup.exe` or `Handoff-0.5.0.msi` (installer), or `Handoff-0.5.0-windows-portable.zip` (no install)

Windows may show "Windows protected your PC" for new downloads: choose **More info → Run anyway**. `SHA256SUMS.txt` lists the checksum of every file.
