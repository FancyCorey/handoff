CREDIT: PODSWITCH
  Handoff's approach to connecting and releasing Bluetooth audio devices
  was adapted from PodSwitch by Felip6499
  (https://github.com/Felip6499/PodSwitch). No PodSwitch source file was
  copied; the techniques were re-implemented:
    - Android: the A2DP profile proxy, the hidden
      BluetoothA2dp.connect()/disconnect() calls via reflection, verifying
      the connection state with a bounded retry, playback-start detection,
      and the connectedDevice foreground service type.
    - Windows: enumerating paired devices and toggling audio services with
      BluetoothSetServiceState (disable, then enable), and start-at-login
      through the per-user Run registry key.
  Because the work is derived from PodSwitch, its copyright notice and
  license are reproduced in section 2.
